# Getting Started

Start here if you've never used `mscompress` before.

1. [Install](installation.md) the binding or CLI you'll use.
2. Skim the [concepts](concepts/index.md) — mzML, MSZ, MSZX, lossy vs lossless.
3. Use the [profile picker](choosing-a-profile.md) to pick a compression
   configuration that matches your data and goals.
4. Jump to the interface you want: [Python](../python/quickstart.md),
   [Node.js](../node/quickstart.md), or [CLI](../cli/quickstart.md).
